# zemlinski.github.io

Privacy policies and data deletion pages for my apps, served by GitHub Pages:

| Page | URL |
|---|---|
| Den: privacy policy | https://zemlinski.github.io/den/privacy/ |
| Den: deleting your data | https://zemlinski.github.io/den/delete/ |

Each app has its own folder; `index.md` in a folder becomes that folder's page. Pages builds the site with Jekyll on every push to `master` and has it live within a minute or two.

The repository must stay **public**: GitHub Pages on a private repository needs a paid plan.
